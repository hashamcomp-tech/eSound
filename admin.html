Tunnel configuration & update guide

How to Update the Tunnel URL
  1. Start your Cloudflare tunnel
    Run the command below in your terminal, replacing PORT with the local port your service is listening on.
    cloudflared tunnel --url localhost:PORT
  2. Grab the generated URL
    Once the tunnel starts, Cloudflare will print a URL ending in *.trycloudflare.com. Copy the full URL from the terminal output — it changes every time the tunnel restarts.
  3. Update tunnel-config.json
    Open tunnel-config.json in your GitHub repo and paste the new URL into the tunnel_url field. See the reference schema below.
  4. Commit & push
    Push the change to your default branch. GitHub Pages will rebuild within a minute, and the status page will pick up the new URL on its next 30-second refresh — no manual reload needed.
    git add tunnel-config.json && git commit -m "update tunnel url" && git push
tunnel-config.json reference
{
  "tunnel_url":  "https://your-tunnel.trycloudflare.com",
  "github_repo": "https://github.com/you/your-repo"
}

Quick tunnel URLs are temporary. Cloudflare generates a new trycloudflare.com hostname each time the tunnel process starts. Remember to update the config file every time you restart the tunnel.
