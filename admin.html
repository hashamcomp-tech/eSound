One-Time Setup — Auto-Detect New Tunnels
  1. Set your GitHub token & repo
    Open watch-tunnel.sh and set GITHUB_REPO, or export GITHUB_TOKEN once in your shell profile. This is the only manual step — ever.
    echo 'export GITHUB_TOKEN="ghp_your_token_here"' >> ~/.zshrc
  2. Install the watcher as a background service
    Run setup-watcher.sh once. It registers a LaunchAgent that starts on login, restarts itself if killed, and tails eSound's tunnel.log continuously.
    chmod +x setup-watcher.sh && ./setup-watcher.sh
  3. Forget about it
    Every time eSound's tunnel restarts — a reboot, a crash, a network blip — Cloudflare assigns a new *.trycloudflare.com URL. The watcher notices the new line in the log within seconds, diffs it against the last URL it pushed, and updates tunnel-config.json on GitHub automatically. No manual copy-paste, no terminal, no git push.
  4. Watch the status page update itself
    GitHub Pages rebuilds within a minute of the push, and the status page picks up the new URL on its next 30-second refresh — no manual reload needed.
tunnel-config.json reference
{
  "tunnel_url":  "https://your-tunnel.trycloudflare.com",
  "github_repo": "https://github.com/you/your-repo",
  "last_updated": "2026-08-21"
}

This file is now managed automatically. The watcher writes to it directly whenever a new tunnel URL appears — you shouldn't need to edit it by hand unless something's misconfigured.
